103 pull requests since v0.18.0, across five betas. Mydia now ships a built-in torrent client with an optional experimental VPN, outbound HTTP proxy support, custom posters, EDL commercial skipping, and server-side HDR tonemapping. The player adds end-to-end encrypted cloud backup, peer-to-peer watch-state sync and file sharing, S3-compatible Files libraries, native macOS HDR (EDR) playback, and moves to Flutter 3.50.

There are 4 new migrations, all additive or index updates. Read the upgrade notes before pulling.

## Built-in torrent client

- Fresh installs with no download client configured get a built-in torrent client automatically, with an optional, **experimental** VPN that routes only torrent traffic (`MYDIA_TORRENT_ENABLED=false` disables it) (#1345).
- Configure the built-in client and its VPN from the UI, including speed limits, torrent priority, seeding ratio/time targets, Remove-on-goal action, and split-tunnel routing (#1388, #1389, #1391, #1406, #1408, #1425).
- Unwanted files (samples, extras, episodes already in the library) are skipped, season packs import finished episodes while the rest downloads, and a free-space reserve (`MYDIA_TORRENT_MIN_FREE_SPACE_GB`, default 5) pauses torrents and refuses grabs when disk space runs low (#1408, #1412).
- Upload totals persist across pauses and restarts so seeding ratio goals stay accurate, with an Uploaded amount shown on torrent rows (#1459).
- Torrents seeding after import continue polling, removed torrents clean up files without stranding them in Issues, cancelling an in-flight download offers a "Delete files" checkbox, and the Advanced section stays open while typing (#1425, #1457).

## Downloads and indexers

- Indexers back off on an escalating cooldown ladder (or honour `Retry-After`) after HTTP 429 responses, enforce a unified per-minute and daily search gate, show cooling-down badges, and report per-indexer Requests, 429s, and Skipped stats (#1453).
- Search keeps torrent and NZB copies of a release as separate results, and blank download-client category inputs no longer show a misleading `mydia` placeholder (#1405, #1450).
- Adding a TV show with hundreds of episodes fetches episodes in the background instead of leaving Discover stuck on "Adding..." (#1382).

## Library and streaming

- **Custom posters:** replace any movie or show poster from its detail page with a TMDB/TVDB alternative, an upload, or an image in the media folder; the choice survives metadata refreshes until reset (#1487).
- **EDL commercial skipping:** Mydia reads `.edl` sidecar files (mplayer/Kodi format) during library scans and carries them along when moving files (#1440).
- **HDR tonemapping:** the server tonemaps unsupported HDR formats to SDR when transcoding (using VAAPI or software `zscale`/`tonemap`, probed at boot) (#1441).

## Networking and remote access

- **Outbound HTTP proxy:** configure a proxy in Settings, YAML, or via `MYDIA_PROXY_URL`/`MYDIA_PROXY_BYPASS` (falling back to `HTTPS_PROXY`/`HTTP_PROXY`/`NO_PROXY`), with automatic bypass for local and private hosts, a Test proxy button, and proxy-aware error messages (#1438).
- **Custom iroh relay:** set one or more self-hosted relays under Admin › System › Remote Access or with `IROH_RELAY_URL`, keeping iroh's public relays as a fallback (#1479).
- The NixOS module allows `AF_NETLINK` so remote access sees host network interfaces and LAN players connect directly (#1475).

## Web UI and translations

- Discover has a per-user ignore list: hide a title with the eye-slash button or from the detail dialog, undo from the toast, and reveal ignored titles with "Show ignored" (#1386).
- Discover grids no longer repeat blocks of titles as you scroll, TV Newest First and Oldest First sort by air date, and the Trending, Popular, On The Air and Airing Today tabs stay selected (#1383, #1384).
- Adding or requesting a title opened from the "More like this" rail updates the detail dialog header immediately (#1449).
- Collections sidebar, exclusion, and mobile layout fixes; library and collection stats rows no longer clip the first label; long wrapping badges stay inside the badge on phones; raw Tailwind elements moved to daisyUI components (#1377, #1390, #1434, #1478).
- Updated translations from Weblate, adding Montenegrin and full Serbian translations (#1435, #1451).

## Player

- **Encrypted cloud backup and P2P sync:** opt-in end-to-end encrypted backup using the Mydia relay, iCloud (CloudKit), or Google Drive with recovery-key restore and a Settings › Backup & sync toggle; paired devices sync watch state and pins directly over P2P or through backup when never online together (#1375, #1414, #1418, #1420, #1421).
- **Files libraries:** add S3-compatible buckets alongside local folders, WebDAV and SMB; download items for offline playback, cast to Chromecast with subtitles, stream paired devices' Files libraries over P2P, view on-device Media Info, reconnect SMB shares by hostname when addresses change, and show per-episode stills (#1374, #1398, #1401, #1409, #1413, #1419).
- **HDR and native macOS EDR:** clients advertise only HDR formats they render accurately and Stats for nerds displays source HDR format and tonemapper; macOS renders via mpv `gpu-next` in a native view for HDR10, HLG, and Dolby Vision 8.x EDR output with libplacebo tonemapping on SDR displays and a Diagnostics fallback toggle (#1441, #1444, #1455).
- **Commercial skipping:** skips commercial breaks from Mydia `.edl` sidecars and Plex/Jellyfin markers automatically by default, or offers a Skip Ad button when auto-skip is disabled (#1440).
- **Flutter 3.50 and UI polish:** rebuilt on Flutter 3.50.1 (`material_ui`/`cupertino_ui`, Gradle 9, AGP 9), restoring page transitions while keeping rail and tab switches instant; Servers & devices unifies servers and paired devices led by Mydia servers; Add server uses grouped cards without spurious autofocus; Serbian joins the language picker; plus one-tap remote control, a non-overlapping cast bar, and a macOS playback-exit sidebar fix (#1392, #1397, #1399, #1411, #1435, #1446, #1454, #1482, #1486, #1493).

## Upgrade notes

- **Outbound HTTP proxy:** containers or hosts that already export `HTTPS_PROXY` or `HTTP_PROXY` will now route Mydia's outbound HTTP requests through that proxy, with local and private hosts bypassed automatically (#1438).
- **Custom iroh relay:** a non-`https` `IROH_RELAY_URL` now fails config validation at startup instead of being ignored (#1479).
- **Built-in torrent client:** created automatically only on fresh installs with no existing download clients; disable with `MYDIA_TORRENT_ENABLED=false`. A 5 GB free-space reserve (`MYDIA_TORRENT_MIN_FREE_SPACE_GB`) guards downloads by default (#1345, #1412).
- **Migrations:** 4 new migrations — `discover_ignored_titles` table (#1386), partial unique index on `media_segments` so files can hold multiple commercial-break segments (#1440), `http_requests` on `indexer_search_events` (#1453), and `poster_override` on `media_items` (#1487).

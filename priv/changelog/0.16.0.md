171 pull requests since v0.15.0, across four betas and nineteen days. This release took a little longer to prepare for personal reasons, but has spent extensive time in testing and is very stable. The headline addition is the player's experimental third-party server integration (Infuse-style unified browsing for Plex, Jellyfin, and Stash) alongside multi-server Mydia support. This release also introduces S3-compatible cloud storage for libraries, WebAuthn passkeys and TOTP two-factor authentication, granular age ratings and content access restrictions, official community plugin store support, and standalone Linux AppImage packaging.

Read the upgrade notes before pulling this. There are 16 migrations (additive schema changes, access restriction tables, and Plex migration to a bundled plugin), S3 storage backend support, and the player now requires Mydia server 0.15.0 or newer.

## Storage, libraries and media

- **S3-compatible object storage:** Libraries can live in S3-compatible buckets (MinIO, Ceph, AWS, Cloudflare R2) with read/write support: scan, match, analyze, stream, import, rename, and delete directly with 4-way parallel multipart uploads (#1077, #1081, #1087)
- **Import resilience:** Usenet and debrid downloads move into library folders rather than copying when no seeding is needed, and imports retry gracefully on SMB, NFS, and FUSE mounts refusing chmod (#1088, #1095)
- **Disk file management:** Empty item folders removed from disk upon media deletion, selective file renaming by season or episode, and stricter import matching to prevent misfiling (#897, #939, #958, #959)
- **Metadata corrections & stream links:** Correct matched metadata directly from the media page after accepting, and external player stream links (VLC, Infuse) with action menus on every file row (#1070, #1072, #1075)
- **Jellyfin watch sync & language upgrade:** Watched state synchronizes across every Jellyfin copy of a movie, and the nightly language upgrade sweep stops re-grabbing releases already present on disk (#1083, #1090)
- **Catalog customization & navigation:** Custom display names for library paths via UI or environment variable, smooth library grid scrolling with URL filters and restored back-navigation, catalog export as CSV or JSON, and library filter dropdown (#919, #921, #1015, #1078)
- **Library search ranking:** Search matches in titles rank ahead of description and overview matches (#1042)

## Upgrade notes

Back up first. Sixteen migrations: fifteen schema changes (all additive or column additions) and one Plex data migration to a bundled plugin.

1. **Third-party media servers & player compatibility:** The player now requires Mydia server 0.15.0 or newer. Multi-server and third-party media sources (Plex, Jellyfin, Stash) are in beta; credentials travel strictly in auth headers and are excluded from logs.
2. **S3-compatible storage backends:** Libraries can now reside on S3 object storage. Existing local libraries are unchanged.
3. **Plex migration to bundled plugin:** Native Plex servers automatically migrate to instances of the bundled plex plugin under Host Contract 1.5, carrying over tokens, account connections, and sync state without re-pushing historical progress.
4. **Per-user access restrictions and content rating age:** Accounts can be restricted by category and age rating. Existing libraries backfill missing certifications automatically via background tasks; uncertified media remains hidden from restricted accounts until metadata is fetched.
5. **WebAuthn passkeys & TOTP 2FA:** User accounts can now register WebAuthn security keys/biometrics and TOTP two-factor authentication.
6. **Quality profile grab delay:** Quality profiles support an optional wait window (0–168 hours) before auto-grabbing acceptable releases. Existing profiles continue to grab immediately.
7. **Library custom display names:** Libraries can specify custom display names, defaulting to folder names rather than exposing underlying host paths.
8. **Torrent infohash blacklisting:** Release blacklists track infohashes, propagating bans across all indexers sharing the same torrent.

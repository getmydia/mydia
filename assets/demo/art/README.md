# Demo artwork

These posters and backdrops are AI-generated images made with Figma's image generation.
They illustrate the invented demo library that `mix mydia.demo_seed` creates and that appears in the website screenshots.
None of them is real media artwork: every title, story and person shown is fictional.
Each title has a `<slug>-poster.jpg` (500x750) and a `<slug>-backdrop.jpg` (1280x720), where the slug is the lowercased title with each run of other characters replaced by `-`.

# Tutorials

Tutorials are lessons that take you from nothing to a working result, in a
fixed order, with no choices to make along the way. Follow them once, start to
finish, and you end up with something running.

If you already know what you want to accomplish and just need the steps, you
want a [how-to guide](../how-to/index.md) instead.

- [Get Mydia running](get-mydia-running.md) - install Mydia with Docker Compose and create your admin account
- [Import your first movie](first-library-import.md) - bring one file into your library, matched and complete
